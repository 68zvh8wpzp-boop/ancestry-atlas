Deployment:
1. Extract this ZIP.
2. Upload every extracted file together to the same GitHub Pages repository folder.
3. Keep filenames and relative paths unchanged.
4. Open index.html through the published GitHub Pages URL.

Television presentation:
1. Choose Guided Audio-Visual Family Tour.
2. Choose a family line.
3. Choose Present on television.
4. Connect with AirPlay Screen Mirroring or HDMI.
5. On a phone or tablet, rotate to landscape. The selected tour begins when horizontal.

The browser does not initiate or verify AirPlay. Phone screen mirroring follows the phone's physical aspect ratio; landscape orientation is required for a television-shaped presentation.
