Present on a television

Display this guided tour in a television-optimized landscape layout. Continue controlling it from this device while using AirPlay Screen Mirroring or another display connection.

On a phone or tablet, rotate the device to landscape before the tour begins.

Safari’s bars will also be mirrored. For a clean full-screen television picture on iPhone or iPad, first use Share → Add to Home Screen, then launch the Atlas from its Home Screen icon.

How to connect

iPhone or iPad

  1. Open Control Center.
  2. Select Screen Mirroring.
  3. Select the Apple TV or compatible television.
  4. Return to the Atlas and start TV Mode.

Mac

  1. Open Control Center.
  2. Select Screen Mirroring.
  3. Select the television.
  4. Return to the Atlas and start TV Mode.

An HDMI-connected television or projector can use the same TV Mode.

Cleanest iPhone/iPad presentation: open the Atlas from an Add to Home Screen icon before mirroring. iOS controls Safari’s browser bars; the webpage cannot remove them or confirm that mirroring is connected.
