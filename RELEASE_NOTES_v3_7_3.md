# Ancestry Atlas v3.7.3

Input and rollback package: `Ancestry_Atlas_v3_7_2_FLAT_GitHub_Package.zip`.

This release closes the remaining route that could launch James Sheldon Webb's legacy interactive slideshow from television Explore Mode. Every Webb television start now exits mirrored TV Explore Mode and opens the approved direct-play film through the native AirPlay media path.

This matters because Safari's navigation interface is part of device screen mirroring and cannot be removed reliably by webpage styling, especially in landscape. Direct media AirPlay sends the biography film itself, so Safari navigation, tabs, the Atlas tree, and interactive slideshow controls are not part of the television picture.

The interactive Webb slideshow remains available only through the explicitly labeled **Explore Story & Transcript** choice. Other family lines retain television-optimized mirrored Explore/Story Mode until completed direct-play films exist for them.

No approved narration, captions, timing, visuals, genealogy, evidence states, or camera behavior changed.
