ANCESTRY ATLAS - FREE GITHUB PAGES PACKAGE

This folder is ready to publish as a static GitHub Pages site.

FILES TO UPLOAD
- index.html
- Ancestry_Atlas_v1_0_family.pdf
- .nojekyll
- assets/ (if present)

FAST SETUP
1. Sign in to GitHub and create a NEW PUBLIC repository, for example: ancestry-atlas.
2. Upload the CONTENTS of this folder to the repository root. Do not upload only the ZIP.
3. Open the repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. GitHub will give you a free address similar to:
   https://YOUR-USERNAME.github.io/ancestry-atlas/

IMPORTANT PRIVACY NOTE
GitHub Pages on GitHub Free uses a public repository. This Atlas contains information about living family members. Remove or reduce any living-person details you do not want publicly accessible before publishing.

UPDATING LATER
Replace index.html and the PDF with the newer Ancestry Atlas version and commit the changes. The same link will update automatically.
