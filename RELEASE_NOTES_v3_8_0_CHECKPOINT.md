# Ancestry Atlas v3.8.0 — Cross-platform visual checkpoint

Input lineage: `Ancestry_Atlas_v3_7_4_CHECKPOINT_AWAITING_MARION_AUDIO.zip`,
continued through the preserved v3.7.5 production working copy.

This checkpoint is intentionally awaiting approved OpenAI Fable recordings. It
contains no active Alfie narration and no browser-generated speech.

## Cross-platform experience

- Added an isolated `experience-3.8.0` responsive layer loaded after the existing application.
- Measures the visible Safari viewport and responds without reloading the Atlas.
- Uses substantially more vertical space for the phone portrait family tree.
- Hides unhelpful century markers and permanent instructional chrome on phones.
- Moves the evidence key into the phone Menu and keeps it closed at startup.
- Prevents landing and tour-choice surfaces from being covered by the mobile dock.
- Keeps story images full-viewport with compact name, year, caption, controls, flag and map.
- Adds distinct phone portrait, phone landscape, tablet, desktop, 1080p and 4K behavior.

## Navigation

- Closing a person card no longer clears the selected person.
- Direct phone node selections now participate in Back history.
- The phone dock reports whether Expand will show Branch, Atlas or Family view.
- Resize and orientation changes preserve the selected person and branch context.
- Existing lateral-only rotation and visible-center pivot mathematics remain unchanged.

## Biography presentation

- Registered approved visual previews for James Sheldon Webb, Marion Beulah Brenay Webb,
  Charles Albert Brenay, Charles Godfrey Brenay, Ida Mae Gooley, John Peter Gooley and
  Mary Ann Dennis.
- Preserved exact approved photo-context narration text for all seven people.
- Added 35 Brenay/Canada scenes, bringing the verified total to 56 story scenes.
- Added separate image navigation only for silent previews; the locked narration controls
  retain their existing behavior.
- Missing approved audio is stated honestly and never replaced with browser speech.

## Maps and flags

- Replaced the generic locator treatment with network-free SVG regional maps.
- Added Great Lakes, St. Lawrence, Ontario–Michigan, continental, Southwest,
  Arizona, central-European and North Atlantic contexts.
- Solid routes represent supported movement; unresolved paths remain dotted.
- Added terrain, water, borders, route stops and period-appropriate flag treatments.

## Rollback

The v3.7.5 working package and its approved Azure Alfie media remain untouched in
`work_v3_7_5`. The v3.8.0 checkpoint deliberately excludes those legacy audio and
film copies so they cannot be mistaken for the newly approved Fable narration.
