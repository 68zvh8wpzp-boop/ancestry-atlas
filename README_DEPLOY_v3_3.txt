ANCESTRY ATLAS v3.3.0 — FLAT GITHUB PAGES PACKAGE

Input / rollback package:
  Ancestry_Atlas_v3_2_0_FLAT_GitHub_Package.zip

Deployment:
1. Extract this ZIP.
2. Upload every extracted file together to the same GitHub Pages repository folder.
3. Keep filenames and relative paths unchanged.
4. Open index.html through the published GitHub Pages URL.

TV Presentation Mode:
- Select the television/display icon in the Atlas toolbar.
- Choose How to connect for AirPlay Screen Mirroring instructions, or Start TV Mode for the television layout.
- The originating iPhone, iPad, or Mac remains the controller. The webpage does not initiate or verify AirPlay.
- HDMI-connected displays use the same mode.

Important audio note:
The approved narration remains James_sheldon_webb.mp3 (Azure Alfie). The input v3.2.0 package did not contain those MP3 bytes. Add the approved file beside index.html without renaming it. No synthetic narration was generated for this release.

Verification:
Run `node verify-package.mjs` from the extracted folder. The verifier reports the approved MP3 as missing until it is supplied.
