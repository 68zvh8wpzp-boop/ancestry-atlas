# Ancestry Atlas v3.8.7 — stable approach, period locators, and reversible phone navigation

This release restores the approved James Sheldon Webb birth-frame geography treatment and closes four phone interaction gaps found during production review.

## Guided entrance

- Begins as a single distant point of light.
- Approaches the selected branch with logarithmic scale and a restrained decaying spiral.
- Solves label placement once at the destination and retains those offsets during motion, preventing frame-to-frame name-card shudder.
- Cancels superseded focus animations so two camera loops cannot compete.

## Flag and locator contract

- Arizona uses the 1917 state-flag design with the approved archival caption `ARIZONA • 1912`.
- Webb's Mesa and St. Johns scenes use a beige, cropped period-style Arizona locator with one scene-specific dot and label.
- The expanded map remains dismissible and gives the locator—not a large flag—the primary visual area.

## Album contract

- Every album entry point now calls the same builder before rendering.
- Verified story photographs, portraits, and documents populate before All / Portraits / Documents and All branches filters are shown.

## Phone tree navigation

- A Names control exposes the selected person's direct lineage branch without opening every node card.
- Family neighborhoods reserve the immediate child and grandchild route before filling deeper ancestors.
- Tapping blank tree space or closing a node card releases focus while keeping the visible branch available for browsing.
- Branch Names can return to the compact local family view.
