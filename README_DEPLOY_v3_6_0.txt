ANCESTRY ATLAS v3.6.0 — FLAT GITHUB PAGES PACKAGE

Upload the CONTENTS of this package to the existing GitHub Pages publishing folder. Do not upload the ZIP itself as a single file.

This release uses v3.6.0-specific runtime filenames to prevent an older cached script or stylesheet from mixing with the new index.html. After GitHub Pages publishes, close any prior Safari tab completely and reopen the site. The landing screen must show BUILD v3.6.0.

IPHONE / IPAD CLEAN PRESENTATION
1. Open the published Atlas in Safari.
2. Use Share → Add to Home Screen.
3. Launch Ancestry Atlas from the new Home Screen icon.
4. Choose Guided Audio-Visual Family Tour and the family line.
5. Choose Present on television, rotate to landscape when prompted, and use Control Center → Screen Mirroring.

The Home Screen launch removes Safari's address and tab bars. A normal Safari webpage cannot remove Safari's own browser chrome.

MAC / HDMI
Choose the tour and Present on television. Use Control Center → Screen Mirroring for AirPlay, or connect the display by HDMI. Fullscreen is requested only after the user starts TV Mode; the presentation continues if fullscreen is unavailable.

ROLLBACK
Restore the untouched v3.5.2 source folder or, because its supplied ZIP is damaged, deploy the valid untouched Ancestry_Atlas_v3_5_1_FLAT_GitHub_Package.zip.
